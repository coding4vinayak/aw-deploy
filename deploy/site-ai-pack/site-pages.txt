# One entry per line: `path | human label`. The label is the link text in the
# index; the page's own <title> becomes the description when it says something
# the label does not.
#
# This list is the judgement call, and it is deliberately explicit: a page that
# is not listed here is not published in the index or the sitemap, so every
# omission is a decision somebody can see and change. The generator refuses to
# run if a listed path is not in the repository, and prints the pages that
# exist but are not listed.
#
# The site is a static services site. There are no product pages and no prices
# on it — the Abetworks product suite is sold from its own hosts, which the
# site's own sitemap links to, and the index lists those hosts as links
# without claiming anything about them that the site does not say.
